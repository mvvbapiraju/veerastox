# AGENTS.md


## Instruction Capture Policy

Whenever the user provides a new instruction for how work should be done in this repository, add that instruction to `AGENTS.md` so it persists for current and future chats.

## Change Confirmation Policy

Before applying any code changes, always:
1. Explain what will be changed.
2. Ask for explicit user confirmation.
3. Wait for a clear approval response (for example: `yes`) before editing files or running mutating commands.

This policy applies by default for all work in this repository, including future chats.

## README Sync Policy

For every new feature/functionality request, and for any codebase change, always update `README.md` in the same task so documentation remains current.
